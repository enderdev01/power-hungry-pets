# Visual System

## Direction
Polished digital tabletop card game.
Warm physical table feel.
No sci-fi HUD.
No glassmorphism-heavy UI.

## Card ratio
Use 63:88 ratio.

## Corners
12px desktop
10px mobile

## Shadows
Soft physical shadow.
No neon glow.

## Typography
Card value: large bold display
Card name: medium semibold
Effect text: compact readable serif/sans depending final art

## States
- normal
- hover
- selected
- disabled
- protected
- eliminated
- forced-play
