# Table Scene Spec

## Table
Top-down / slight perspective.
Dark green or dark warm tabletop.
Subtle felt/paper texture.
Avoid repeating obvious pattern.

## Zones
- draw deck: center
- hidden card: next to deck
- opponents: around perimeter
- current player hand: bottom
- public discards: near each player
- victory tokens: beside player name

## Desktop
Full table visible.

## Mobile
Compress opponents into upper arc/list.
Own hand remains dominant.
