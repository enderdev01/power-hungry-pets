# Card Component Spec

## Structure

Card
├── artwork
├── value badge
├── name
└── effect summary

## Sizes

Desktop hand card:
- width: 180px
- height: 251px

Opponent/public discard:
- width: 96px
- height: 134px

Mobile hand card:
- width: 145px
- height: 202px

## Interaction
- tap/click to inspect
- selected card lifts 12px
- playable card has subtle border emphasis
- disabled card is dimmed
